# LOAD-ME — первое сообщение (скопируй и отправь)

Гайд лежит в `CLAUDE.md` в корне репозитория и подхватывается автоматически в начале сессии — отдельно грузить или упоминать его не нужно. Работать с видео можно только там, где есть выполнение кода (ffmpeg): **Claude Code** или Cowork. В обычном чате mov/mp4 не открываются — там можно только обсуждать сценарий и критиковать по гайду.

## Как передать исходники

Файлы до 100 МБ проходят обычным `git push`, но через веб-интерфейс GitHub загружаются только файлы до 25 МБ. Поэтому видео кладём в **релиз**:

1. Репозиторий → **Releases** → *Create a new release* → тег любой (`Video2`, `Video3`…).
2. Перетащить видео в **Attach binaries** (лимит 2 ГБ на файл).
3. Опубликовать и дать ссылку на релиз в сообщении.

Иконку приложения, скриншоты и шрифты класть прямо в репозиторий — они мелкие.

## Что приложить к сообщению

- **Исходники** (mov/mp4) — все дубли, как сняты, без предварительной обрезки.
- **Расшифровка с таймкодами** — экспорт субтитров из редактора (CapCut / Premiere / DaVinci → SRT). Без неё речь распознаётся оффлайн-моделью, и фальш-старты приходится подтверждать вручную.
- **Скриншоты** приложений и сервисов, которые надо показать в ролике.
- **Музыка**, если нужна: сгенерировать или скачать её из среды нельзя, только положить файлом.
- CTA всегда один — «ссылка в шапке профиля», он уже прописан в гайде.

## Что среда умеет сама

- Распознать речь оффлайн с таймкодами по словам (sherpa-onnx, русская модель).
- Собрать двухслойные субтитры, поставить иконку, нормализовать звук, прогнать QA измерениями (safe-зоны попиксельно, LUFS, длительность карточек).
- Скачать OFL-шрифты с кириллицей и нарезать статические начертания.
- Синтезировать SFX процедурно.

## Чего среда не умеет

- Слышать звук: интонация, фальш-старты и «слипшиеся» стыки подтверждаются человеком.
- Скачать музыку или SFX-паки — сеть закрыта, кроме GitHub / pypi / npm / Google Fonts.
- Сгенерировать музыку.

## Быстрая подготовка материалов

Скриншоты ключевых кадров пачкой:

```bash
ffmpeg -i video.mp4 -vf fps=1/2 frames/%03d.jpg
```
