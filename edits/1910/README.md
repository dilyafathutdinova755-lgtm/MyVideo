# Ролик 1910 — «ответы вверх ногами»

Скрипты монтажа. Видеоряд исходника не резался (сплошной дубль 14.98с, повторов нет) — всё поверх него.

Для сборки положить рядом: `src.mp4` (исходник), `IMG_0884.png` (иконка), `fonts/` (GolosText, Manrope, PlayfairDisplay-Italic из google/fonts), затем:

```
python3 sfx.py && ./build.sh out.mp4
```

- `render.py` — плавные зумы видеоряда + графический слой (карточки, бегущая подпись, лист ответов с глазами, строки разбора, шкала с замком, стрелки, иконки); кадры rgb24 stdin → stdout. `--png <папка_с_кадрами> 4.4 ...` — стоп-кадры для QA, `--groups` — тайминги бегущей подписи.
- `sfx.py` — процедурные SFX (pop / ping / whoosh) по точкам моушн-хитов.
- `build.sh` — наложение, микс, двухпроходный loudnorm к −14 LUFS / TP −1.4.

Расшифровка — Whisper medium (sherpa-onnx, модель из GitHub-релиза: Hugging Face закрыт сетевой политикой), тайминги слов — по провалам громкости + распределение по слогам.

## Версия по плейбуку (`pb.py`, `build_pb.sh`)

Собрана только по «Плейбуку динамичного монтажа в пастельной палитре», без опоры на остальные материалы репозитория.
Нужны шрифты в `fonts/`: Manrope, Unbounded, Oswald, CormorantGaramond-Italic (google/fonts). Сборка: `./build_pb.sh out.mp4`. Звук исходника копируется без обработки.
