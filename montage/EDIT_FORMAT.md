# Формат edit.json

Партитура одного ролика. Всё время — в секундах исходника. Координаты — пиксели кадра 1080×1920
(`cx`, `cy` — центр элемента). Образец: `projects/1910/edit.json`.

```json
{
 "source": "source.mp4",            // путь к видео относительно edit.json
 "fps": 25, "duration": 14.98,      // fps может быть дробным: 31.578947 = 600/19
 "transcript": {...},               // содержимое transcript.json (фрагменты речи)
 "subtitles": {"baseline": 1556, "groups": ["в бумажных сборниках ЕГЭ", "..."]},
 "zoom": {"anchor": [380, 700], "keys": [[0, 1.0, null], [2.05, 1.12, "ease"], [3.55, 1.15, "lin"]]},
 "events": [ ... ]
}
```

- **subtitles.groups** — смысловые группы по 2-4 слова. Вместе они обязаны покрыть все слова расшифровки
  по порядку (регистр и «ё» не важны). Время групп считается само. Короткий хвост (<0.35с) лучше приклеить
  к соседней группе.
- **subtitles.overrides** — `[[t0, t1, baseline]]`: на время демонстрации экрана/предмета поднять субтитры, чтобы не закрывать его.
- **zoom.keys** — `[время, масштаб, кривая сегмента, который заканчивается в этой точке]`: `"ease"` — плавный
  переход (0.4-0.5с), `"lin"` — медленный дрейф. `anchor` — точка, которая остаётся на месте (лицо).

## Цвета и шрифты

Цвета по имени: `milk ink muted cream vanilla blush lavender sky mint peach plum`.
Одна пара пастелей на ролик (например, `blush` + `vanilla`), остальное — по отдельной причине.

Роли шрифтов: `BODY` (Manrope — субтитры), `WIDE` (Unbounded — главный акцент), `COND` (Oswald — узкая строка),
`EDIT` (Cormorant Italic — редкий курсив). В композиции обычно две роли.

## События

Общие поля: `t0`, `t1` — начало и конец; `"on_slide": true` — элемент лежит на слайде (тёмный текст, без теней);
`motion` — вход: `M01` подъём, `M02` упругий акцент, `M04` с наклоном, `M07` предмет, `FADE`.

| type | что это | поля |
|---|---|---|
| `composition` | крупная надпись из 1-3 строк, строки раскрываются по очереди | `t1`, `cy`, `cx`; `parts: [{text, role, size, color, t, motion, dx, lead, track, flip}]` |
| `text` | одиночная строка | `text, role, size, color, cx, cy, t0, t1, motion, rot` |
| `plaque` | тёмный текст на пастельной плашке | `text, size, fill, color, cx, cy, t0, t1` |
| `slide` | полноэкранный слайд с фоном | `t0, t1, blob, blob_at, bg, subs: "show"/"hide"` |
| `app_icon` | иконка ЕГЭ Тренажёра (оригинальный файл) | `cx, cy, size (280 на видео), t0, t1` |
| `sheet` | лист «ОТВЕТЫ», может перевернуться | `cx, cy, t0, t1, flip_t, title, accent, tilt` |
| `eyes` | глаза выглядывают из-за предмета | `cx, cy, t0, t1` (ставить над верхним краем предмета) |
| `doc_card` | белая карточка-документ | `cx, cy, w, h, t0, t1` |
| `writelines` | строки дописываются | `cx, cy, widths, per, t0, t1` |
| `lockpath` | путь из сегментов + замок открывается | `cx, cy, segments, fill_t0, fill_dur, t0, t1` |
| `arrow` | стрелка прорисовывается | `dir (up/down/left/right), length, cx, cy, color, draw, bob_from, t0, t1` |
| `link` | иконка ссылки | `cx, cy, color, t0, t1` |
| `nowifi` | перечёркнутый Wi-Fi, «без интернета» | `cx, cy, size, t0, t1` |

`subs: "hide"` на слайде — если текст слайда сам дословно повторяет речь; иначе `"show"`, и субтитры
на слайде становятся тёмными.

Зоны: лицо не закрывать; поля по бокам ≥80px; нижние ~330px — под интерфейс площадки; крупные надписи
на видео — в районе груди (cy 1150-1200), субтитры — базовая линия 1556.
