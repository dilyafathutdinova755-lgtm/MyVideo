# Монтаж ролика

Источник правил — `montage/PLAYBOOK.md` (плейбук автора) + обязательные правила ниже. Эталон результата —
`projects/1910/edit.json`: по плотности, слайдам и иллюстрациям каждый ролик должен быть не хуже. Других гайдов и
примеров в репозитории нет и не надо их искать: автор просил делать только по плейбуку.

## Обязательные правила автора (важнее плейбука при конфликте)

1. **Полноэкранные слайды с фоном — в каждом ролике.** Минимум один, а лучше по одному на каждый смысловой
   поворот (ориентир — раз в 10-15 секунд). Слайд = `slide` + содержимое с `"on_slide": true`: молочный фон,
   одно размытое пастельное пятно, тёмный текст, схема (стрелка, плашка, путь с замком, карточка-документ).
   Длина слайда 1.8-3.5с. Текст на слайде появляется после того, как фон закрыл кадр (+0.3с от начала).
2. **Иконка ЕГЭ Тренажёра — только оригинальный файл** `montage/assets/ege_icon.png` (событие `app_icon`).
   Не перерисовывать, не перекрашивать, не заменять карточкой с названием, не делать полупрозрачной —
   по иконке приложение узнают в сторе. Появляется, когда в речи упоминается приложение, и держится до конца
   ролика; на слайдах про приложение — тоже.
3. **Рисованные иллюстрации-метафоры** на смысловых поворотах: лист, который переворачивается; глаза, которые
   подглядывают; строки, которые дописываются; путь из сегментов с замком; стрелка со ссылкой. Без выдуманных
   цифр, отзывов и интерфейсов. Одна крупная иллюстрация за раз, вне лица.
4. **Плавные зумы видеоряда** на смысловых границах: 1.00-1.16× для 1080p (до 1.28× для 4K), переход 0.4-0.5с
   ease, между ними медленный дрейф. Якорь — лицо.
5. **Звук исходника не трогать** (без нормализации и эффектов), если автор не попросил.
6. Видеоряд не резать и не переставлять — дубли и паузы не вырезаются, если автор не попросил.
7. Remotion не использовать — только `montage/engine.py` (Python + ffmpeg).

## Порядок работы

1. `bash montage/setup.sh` — зависимости, шрифты, модель Whisper (первый раз 2-4 минуты).
2. Создать `projects/<имя>/`, положить видео как `projects/<имя>/source.mp4` (не коммитится).
   `ffprobe` — разрешение, fps, длительность. Если не 1080×1920, привести: `ffmpeg -i in -vf scale=1080:1920 -r <fps> ...`.
3. `python3 montage/transcribe.py projects/<имя>/source.mp4 projects/<имя>/transcript.json`, затем вычитать:
   исправить ошибки распознавания («ег» → «егэ»), перенести куски слов, разрезанные на границе фрагментов.
   Время фрагментов не трогать. Быстрая речь даёт ошибки в числах и названиях — спорные места перепроверить
   `python3 montage/recheck.py <видео> <начало> <конец> ...` (окна 5-9с, два прогона: совпало в обоих = надёжно).
   Число, в котором нет уверенности, на экран не ставить; сомнительные места назвать автору в отчёте.
4. Посмотреть кадры (сетка раз в 0.5-1.5с + один кадр в полный размер с сеткой): где лицо, руки, свободные зоны
   и **моменты, когда героиня показывает экран или предмет** — их не закрывать ни слайдом, ни надписью, ни
   субтитрами (`subtitles.overrides` поднимает субтитры, надписи уходят на свободную стену).
5. Написать `projects/<имя>/edit.json` (формат — `montage/EDIT_FORMAT.md`, образец — `projects/1910/edit.json`):
   смысловые блоки → для каждого функция (тезис / предмет / сравнение / процесс / реакция / пауза / финал) → приём.
   Чередовать: крупная надпись на видео → иллюстрация → слайд → тихий участок. Не каждое слово — акцент.
6. `python3 montage/engine.py projects/<имя>/edit.json --stills <6-10 моментов>` — проверить стоп-кадры
   (лицо свободно, текст в полях, нет наложений, слайды читаются). Править edit.json, повторять.
7. `python3 montage/engine.py projects/<имя>/edit.json --out projects/<имя>/out` → `final.mp4` + `subs.srt`.
   Проверить сеткой кадров раз в 0.33с. Слои для ручной доработки (`--layers`: base_zoom.mp4 + overlay.mov
   ProRes 4444 с альфой, ~20 МБ на секунду) — только если автор попросил.
8. Отправить `final.mp4` автору (SendUserFile). Закоммитить `projects/<имя>/edit.json` и `transcript.json`
   в рабочую ветку и запушить. Коротко: что где стоит, что проверено, что додумано самостоятельно.

## Правки автора

Правка «сдвинь / поменяй текст / убери / добавь слайд» = правка `edit.json` и повторный рендер. Если правка
должна повторяться во всех роликах — дописать её в раздел «Обязательные правила» этого файла.
Если нужного типа графики в движке нет — добавить компонент в `montage/engine.py` (в BUILDERS) и описать
в `montage/EDIT_FORMAT.md`, а не рисовать разово в стороннем скрипте.
